# ICT 인턴십 회사 랜딩 페이지

ICT 인턴십 과정에서 제작한 회사 솔루션 홍보용 랜딩 페이지입니다.  
사용자가 서비스에 대해 이해하고 상담 또는 회원가입으로 이어질 수 있도록 **CTA 중심의 사용자 흐름을 고려해 설계한 웹 페이지**입니다.

---

## 프로젝트 개요

- **기간** : 2개월  
- **역할** : 프론트엔드 개발  
- **목적** : 회사 솔루션 홍보 및 사용자 유입을 위한 랜딩 페이지 제작  

---

## 사용 기술

- JavaScript
- Node.js
- Tailwind CSS
- MongoDB

---

## 주요 기능

### 랜딩 페이지 UI 구현
- 회사 솔루션 소개 및 주요 장점 콘텐츠 구성
- CTA(Call To Action) 중심의 랜딩 페이지 구조 설계

### 기능 소개 페이지
- 솔루션 기능 상세 설명 페이지 구성
- 서비스 기능별 정보 전달 UI 구현

### 컨설팅 유도 페이지
- 서비스 상담 요청을 유도하는 페이지 UI 구성

### 가격 안내 페이지
- 서비스 구독 구조 안내 페이지 구현

### 로그인 / 회원가입
- 사용자 계정 생성 및 로그인 기능 구현

---

## 배운 점

- 랜딩 페이지에서 **사용자가 첫 화면에서 어떤 행동을 하도록 유도할 것인지**에 대한 UX 설계 경험
- 서비스 장점을 효과적으로 전달하기 위한 **콘텐츠 구성 및 페이지 흐름 설계 경험**
- 사용자가 불편함을 느낄 수 있는 요소를 고려한 **사용자 친화적 UI 설계 경험**
